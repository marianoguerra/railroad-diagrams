# Contributing

Thanks for helping improve the project.

1. Discuss substantial API changes in an issue before implementation.
2. Create a focused branch and include tests for behavioral changes.
3. Run `npm ci` and `npm run release:check` before opening a pull request.
4. Keep public APIs documented and update `CHANGELOG.md` for user-visible changes.

Bug reports should include the smallest diagram that reproduces the problem, rendering options, Node/browser version, and actual versus expected output.
